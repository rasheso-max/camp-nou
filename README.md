# Spotify Camp Nou

A responsive, interactive FC Barcelona stadium experience built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Explore

- Switch between dark and light themes.
- Open the stadium feature tabs for details about the roof, VIP experience, museum, and pitch.
- Expand the legends cards to revisit Messi, Cruyff, and Xavi's Barça achievements.
- Estimate ticket totals by match, seating tier, and quantity. Displayed prices are illustrative.
- Answer three Camp Nou trivia questions and see your score update as you play.
